REST API

The routes the web app uses today
built
GET · POST /api/projectslist and create projects
PUT /api/projects/{id}/data · POST …/data/sampleattach a table or a studied sample
POST …/solution/proposal · PUT …/solutionpropose and save the solution
POST …/stages/{stage}/run · …/approve · …/runrun a stage, approve it, or run everything left
POST /api/projects/{id}/askask the project; answers cite records
GET …/export/notebook · report · sft.ipynb, Markdown report, training examples
GET · POST /api/intern/sessions · …/messageintern sessions with a budget
GET /api/evidence/{record_id} · /api/knowledgeevidence records and the knowledge view
Write requests (POST, PUT, PATCH, DELETE) need the X-DCLab-Token header from GET /api/config; the server answers only on 127.0.0.1 and localhost.
