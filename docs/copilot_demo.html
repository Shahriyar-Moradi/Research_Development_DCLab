FixDrop duration (and anything derived from it) from the model's inputs before splitting.

Oversampling before the split

Rows are duplicated (resampled with replacement) before any train/test split. Copies of the same row end up in both train and test, so the model is graded on rows it has already memorized.

FixSplit first, then oversample the training part only; better, use imblearn.pipeline.Pipeline so it happens inside each CV fold.

Preprocessing fitted before the split

StandardScaler.fit_transform learns statistics from all rows before the train/test split. For simple scaling the measured effect is tiny, but it builds the habit that makes selection, resampling and encoding leak badly.

FixCreate the split first, or wrap preprocessing and model in one Pipeline so every statistic is learned from training data only.

FixReport ROC-AUC or average precision for ranking, log loss or Brier for probability quality, and precision/recall at the threshold you will actually use.
