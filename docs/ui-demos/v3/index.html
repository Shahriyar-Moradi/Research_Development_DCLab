UI demo v3 · 20 Nov 2026

A demo only: no product code is changed. The numbers are examples, shaped like the Telco churn project.

Removed

  • The Data · Plan · Run · Evidence box above the chatA conversation is not a pipeline. A project shows one status line instead.
  • exp/churn, Py3.11 · DuckDB, the top search boxFacts about the machine, not about the work. They live in Settings → Developer.
  • "Navigation", "Workspace", "Project pipeline" headersThe sidebar has two lists now: projects and recent chats.
  • Developer / Data science switch in the sidebarMoved to Settings → General.

Moved

  • Compute & jobsSettings → Jobs & usage. You look at it rarely; it does not need a sidebar line.
  • Workflow DAG, Datasets, Notebook, Leakage, ModelsTabs inside a project. The graph is still there: "Steps" on the project's Overview.
  • Evidence library, Research lab, Benchmark, Policy modelOne "Library" entry. Research pages are for the team, not customers.
  • Intern (Autonomous Agent)Not a separate page: "Let DCLab run it" is a choice inside the chat.
  • Domain packs, Integrations, AdminSettings.

Added

  • Features tabEvery feature: how it is made, from which columns, whether it is known at prediction time, kept or dropped, and how much it helps.
  • A Claude-style chatCentred column, solid composer at the bottom, questions you click to answer, and the problem card in a side panel you open.
