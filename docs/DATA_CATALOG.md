# Data catalog

_Generated by python -m dclab_rnd.data_catalog from the contracts and the code; never edited by hand._ dclab-core 0.55.0.

## Consent and retention

- **operate** — kept to run the product; never leaves
- **improve** — may be read and turned into evaluation cases
- **train** — may become training data
- **rule** — a record leaves only if it was written at that level (its stamp) and the switch is on now

- events (the session record): `DCLAB_RETENTION_EVENT_DAYS`, default 730 days
- prompts and replies inside events: `DCLAB_RETENTION_MODEL_TEXT_DAYS`, default 365 days
- a draft's raw upload: `DCLAB_RETENTION_RAW_DAYS`
- a deleted project, draft or session: `(immediate)`

## Field classes

| Class | Letter | Meaning |
|---|---|---|
| meta | M | ids, codes, names of things; leaves at improve and train |
| count | C | numbers; leaves at improve and train |
| person_text | P | what a person typed; leaves redacted |
| agent_text | A | what an agent said; leaves redacted |
| model_text | X | a prompt or a reply; leaves only at train, redacted, and only if the workspace kept it and the purpose was allowed to keep it |
| cell_values | V | a value of a table; never recorded |
